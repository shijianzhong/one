# Product

## Register

product

## Users

Solo developers and technical operators who use the app as a local AI workbench. They switch between chat, tasks, workspace files, terminal output, and coding CLI sessions while staying inside one desktop window.

## Product Purpose

ONE coordinates local workspaces, MainAgent conversations, coding runtimes, workflow capabilities, and trigger integrations. Success means users can delegate coding or operational tasks, inspect progress, and respond to required confirmations without losing context.

## Brand Personality

Focused, technical, calm.

## Anti-references

Avoid marketing-style hero layouts, oversized decorative UI, card-heavy dashboards, and interfaces that require excessive window width for routine task work.

## Design Principles

- Prioritize usable density over decoration.
- Keep terminal, chat, and task panels readable at common laptop widths.
- Make state and required user actions obvious without flooding the main conversation.
- Prefer familiar product UI affordances over invented controls.
- Preserve direct access to the underlying terminal while MainAgent remains the readable intermediary.

## Accessibility & Inclusion

Use clear contrast, stable layout, visible focus states, and compact but readable type. Motion should communicate state and should not block task flow.
